# draw.io example corpus

The `.drawio` and `.xml` files in this directory are unmodified examples from
[jgraph/drawio-diagrams](https://github.com/jgraph/drawio-diagrams) at revision
`cc78dc2e7df8cf3ad437e6f876fbc33d2d0b7e01`. They are distributed under the
[Apache License 2.0](../../crates/thinoda-ui/assets/icons/LICENSE); the upstream
repository also contains its [license](https://github.com/jgraph/drawio-diagrams/blob/cc78dc2e7df8cf3ad437e6f876fbc33d2d0b7e01/LICENSE).
The accompanying PNGs are rendered page previews, not byte-identical upstream
files; a `.page-N` suffix identifies a later page. The `.url` files are links to
public draw.io resources.

The examples are used by the draw.io corpus integration test and are not
bundled with the application. Set `THINODA_DRAWIO_CORPUS` to exercise a
different local corpus.
